# Test Data Generator

A free, offline test data generator that works directly in the browser — no API key, no installation required.

## Features
- ✦ **Text Generator** — Generate names, emails, phones, addresses, UUIDs, dates and more
- ⊞ **Structured Data** — Generate JSON, CSV, XML, SQL, YAML instantly
- ⬡ **File Generator** — Download sample files (PDF, DOCX, XLSX, TXT, CSV) at exact sizes

## Usage
Just open the link — everything runs offline in your browser using pure JavaScript.
